# Business Requirements - ksf_JobDescriptions

## Project Overview
Job descriptions linked to recruitment, performance, teams, and HRM.

## Problem Statement
- Job descriptions needed for postings
- Link to competencies (Performance)
- Link to team/role (Teams)
- Link to salary grade (HRM/Compensation)

## Scope

### Job Description Structure
- Title
- Department
- Grade
- Summary
- Responsibilities (list)
- Required Skills
- Preferred Skills
- Education Requirements
- Experience Requirements
- Certifications Required
- Typical Rate/Rage

### Links To
- ksf_Recruitment: Job postings from description
- ksf_Performance: Competencies to assess
- ksf_Teams: Role specifications
- ksf_Compensation: Grade alignment
- ksf_Training: Required training

### Features
- Template system
- Version history
- Clone from existing
